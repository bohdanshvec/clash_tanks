## Проект и обязательные границы

`clash_tanks` — учебная браузерная пошаговая карточная стратегия про танки. Проект вдохновлён WoT: Generals, но использует собственные названия, правила, карты и материалы.

Язык пользовательского интерфейса — украинский. Все новые и изменяемые надписи интерфейса, кнопки, подписи, заголовки и сообщения игроку должны оставаться на украинском языке.

Главный архитектурный инвариант:

```text
Decision Provider → Action → GameActionRunner → GameEngine → GameState
```

- `GameEngine` — единственный арбитр игровых правил.
- UI, Controllers, JavaScript, Stimulus, Turbo и AI не изменяют `GameState` напрямую.
- `GameActionRunner` применяет действия и сохраняет только успешный результат.
- AI использует только разрешённое состояние и серверный список допустимых действий.
- Скрытая информация противника не должна передаваться UI или AI.
- Не придумывать игровые механики вне `GAME_RULES.md`.
- Не изменять игровую механику без согласования с пользователем.
- Не вводить Redis.
- Не изменять и не удалять PostgreSQL 12 и PostgreSQL 14 без прямого указания пользователя.

При противоречии документации, кода и подтверждённых решений сообщить пользователю. Не выбирать самостоятельно, какое правило считать правильным.

## Правила работы с изображениями

Перед созданием или подключением графики сверяться с `ART_STYLE.md`.

Утверждённые форматы игровых карт:

- `1024 × 1024 px` — квадратный формат объектов на игровом поле: штабов, техники и взводов.
- `848 × 1264 px` — вертикальный формат полных карт в каталоге, колодах, редакторе и руке игрока.

Изображение объекта и его прозрачная рамка — отдельные ресурсы. При многослойном отображении рамка располагается над иллюстрацией.

Эти размеры относятся к исходным ресурсам, а не к обязательным CSS-размерам на экране. CSS может масштабировать изображение без создания отдельных файлов для разных размеров отображения.

Не растягивать изображения с искажением пропорций. До подключения проверять соответствие размеров, взаимное положение слоёв, прозрачность и визуальное совмещение рамки с иллюстрацией.

Не встраивать в PNG динамические названия, характеристики, стоимость или текст способностей. Такие данные должны отображаться интерфейсом из актуального состояния и данных карты.

Разные типы карт могут иметь разные композиции рамок. Единый художественный стиль не означает одинаковое расположение всех характеристик.

На игровом поле текст способности техники не должен перегружать компактную карту. Для техники со способностью предусматривается отдельный визуальный индикатор и способ просмотра описания. Реализация этих элементов фиксируется в `PROGRESS.md` только после фактической проверки.

Для сенсорных устройств нельзя полагаться исключительно на наведение курсора: нужно предусмотреть подходящий способ просмотра дополнительной информации.

Графика и анимации только отображают состояние и события, определённые серверной игровой логикой. Они не меняют правила и не принимают игровые решения.

## Текущая контрольная точка

Stage 1–23 завершены по решению пользователя. Stage 24 находится в работе.

Последняя ранее подтверждённая контрольная точка, приведённая в документации:

```text
Branch: pictures_ui
Commit: b6722b6
Message: fullscreen works
```

Эти сведения исторические и не подтверждают актуальное состояние рабочего дерева. Перед Git-операциями проверять фактическую ветку, коммит и незакоммиченные изменения.

После последующих изменений актуальный статус Git должен проверяться локально:

```bash
git branch --show-current
git log -1 --oneline
git status
```

Не считать старые сведения о `main`, `origin/main` и коммите `2902c4a` описанием текущего рабочего состояния.

## Тестирование и проверка

Запускать тесты при изменении поведения, серверного контракта или игровой логики. Не дублировать существующее покрытие без конкретной причины.

Визуальные изменения проверять в браузере. При изменении ассетов и CSS при необходимости проверять:

```bash
bin/rails assets:precompile
```

Не утверждать, что проверка прошла, если пользователь не сообщил результат или проверка фактически не выполнялась.

Исторические результаты тестов относятся только к соответствующим запускам:

```text
542 runs, 2024 assertions, 0 failures, 0 errors, 0 skips
548 runs, 2061 assertions, 0 failures, 0 errors, 0 skips
549 runs, 2082 assertions, 0 failures, 0 errors, 0 skips
553 runs, 2114 assertions, 0 failures, 0 errors, 0 skips
```

Экспериментальный результат `554 runs, 2125 assertions` относится к состоянию, изменения которого впоследствии были отменены. Не использовать его как результат текущей версии.
